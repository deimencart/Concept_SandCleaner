
# 🧩 CAD Files – Beach Cleaner Robot

This folder contains the mechanical design files, technical drawings, and final 3D model of the **conceptual robotic system for beach waste collection**.

---

## 📐 Final Assembly – Top View

![image](https://github.com/user-attachments/assets/e4045f79-9c2b-4702-88f9-a9c716007008)

This drawing represents the final prototype's top-view layout, showing:
- **Drive wheel placement**
- **Waste collection roller**
- **Motor mounts and mechanical supports**
- **Component housing (battery, control board)**

---


---

## 💬 Design Highlights

- 🛞 Four-wheel structure for improved terrain mobility  
- ♻️ Passive roller-based collection mechanism  
- 🧩 Modular design for electronics and sensor mounting  
- 🧰 Designed in **Fusion 360** using parametric modeling

---

## 📦 Formats Provided

- `STEP` for interoperability and simulation use  
- `STL` for 3D printing of key parts  
- `PDF` drawing for fabrication reference  
- `F3D` for continued editing in Fusion 360
